```
                                                    ↓
                                         结算页（DailySettlementScreen）
                                                    ↓
                                        点击"回家" → 回到主界面
```

## 三、详细设计

### 3.1 主界面改动（HomeScreen.cs）

**按钮改名：**
- "继续主线" → **"校园日常"**
- 点击后进入 `DailyGameScreen`

**进度显示：**
- 学期指示改为"高一上 · Day X/30"
- 保留学期卡片横向滑屏

### 3.2 主玩法界面（DailyGameScreen.cs）

实现 V6.9.3 demo 核心功能：

#### 3.2.1 流水账时间轴
- 33条流水，按时间 7:00-23:00 排列
- 逐字打字机效果（1.6s）+ 橙色光标
- 每条流水显示具体时间

#### 3.2.2 事件触发
- 5个事件位置显示"⚡ 进入事件"脉冲按钮
- 玩家主动点击进入事件
- 事件完成后回到流水账

#### 3.2.3 5个固定事件
| 事件ID | 时间 | 名称 | 描述 |
|--------|------|------|------|
| ev_run | 7:30 | 早操 | 体育委员急报800米 |
| ev_math | 10:00 | 数学 | 数学老师点压轴题 |
| ev_lunch | 12:30 | 午饭 | 食堂拼桌风波 |
| ev_pe | 16:00 | 体育 | 体育课三对三 |
| ev_night | 20:30 | 晚自习 | 班主任突击检查 |

#### 3.2.4 事件弹窗（3选项）
- 🎯 **破局**：思×2+行×1，精力-15 → 智+6/体+3/纪+3/心+2
- ⚡ **稳进**：思×1，精力-8 → 智+3/体+1/纪+2/心+1
- 🤷 **保守**：无消耗，精力-0 → 随机±1属性（60%负/40%正）

#### 3.2.5 精力HUD
- 4档显示：💪充沛(100+) ×1.2 | 😊良好(80+) ×1.1 | 😐一般(50+) ×1.0 | 😩疲惫(<50) ×0.8
- 进度条显眼显示
- 低精力提示横幅

#### 3.2.6 选项影响剧情
- 每个选项有对应的故事分支
- 影响后续1-2条流水文本

#### 3.2.7 结束流程
- 5事件完成 → 推3条结束流水 → 结束语 → 黑屏转场（月亮漂浮）→ 结算

### 3.3 结算页（DailySettlementScreen.cs）

5段结构：
1. **评语**："惊心动魄的一天"/"充实的一天"等
2. **属性+精力**：4属性chip + 精力横排 + 精力曲线图
3. **精彩瞬间**：最高分事件展示
4. **角色独白**：性格立绘 + 独白
5. **双按钮**："回家"/"开启明天"

### 3.4 GameState 新增字段

```csharp
// 精力系统
public int Energy { get; set; } = 100;           // 当前精力
public int DayEnergy { get; set; } = 100;         // 当日初始精力
public List<int> EnergyHistory { get; set; }      // 精力历史曲线

// 天进度
public int DayIndex { get; set; } = 0;            // 当前天数（每学期30天）
public int EventsCompleted { get; set; } = 0;     // 当日已完成事件数

// 广告相关（开发阶段模拟）
public int DayAdCount { get; set; } = 0;          // 当日广告次数
public int EnergyAdCD { get; set; } = 0;          // 广告冷却
```
