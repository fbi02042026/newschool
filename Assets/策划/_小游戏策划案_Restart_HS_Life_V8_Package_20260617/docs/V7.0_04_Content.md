### 5.8 关键事件对话规范

#### 5.8.1 设计哲学

**核心原则：节奏感 = 80% 沉浸流水账 + 20% 关键对话**

- **普通事件（80%）**：纯文字 + 流水账上移，**不弹窗、不立绘、不对话**，保持 3-5 分钟一局的快节奏
- **关键事件（20%）**：触发时切到**视觉小说风格的简版对话**，承担"情绪铺垫 / 性格呈现 / 分支引导 / 炫耀素材"四大功能

> 一句话：**对话是节拍器，不是连续剧**。平时只听到心跳，关键时刻才响起鼓点。

#### 5.8.2 关键事件清单

只有以下事件会触发对话。其他事件保持纯流水账快过。

**对话推进机制：**
- 玩家**点击屏幕任意位置** = 推进下一句对话
- 对话全部播完后，**手牌自动亮起**（高亮 + 微动效）
- 出牌后对话窗口淡出，回到流水账
- 跳过按钮：右上角 `[>>]` 长按 1.5 秒可跳过当前对话（不跳过奖励结算）

**视觉细节：**
- 文字逐字显示（打字机效果，30ms/字）
- 立绘根据台词内容切换表情
- 关键台词有**轻微抖动**或**镜头拉近**（0.2秒动画）
- 对话框背景半透明黑（rgba(0,0,0,0.7)），保证文字清晰

#### 5.8.4 对话撰写规范

**格式标准：**

```yaml
事件ID: DIALOG_001_开学分班
场景: 教室
立绘: 角色主角 + 班主任 NPC
对话脚本:
  - 旁白: "站在陌生的教室里，你深吸一口气。"
    立绘表情: 紧张
  - 班主任: "新同学，先做个自我介绍吧。"
    立绘表情: 平静
  - 旁白: "全班 30 双眼睛看着你。"
    立绘表情: 紧张
  - 班主任: "叫什么？有什么特长？"
    立绘表情: 微笑
  - [对话结束，手牌亮起]
  手牌可选:
    - 死磕书本（学神主·学术类）
    - 机灵应变（文青主·口才类）
    - 暖心鼓励（段子手主·情商类）
    - 主动出击（显眼包主·体魄类）
  出牌结果:
    - 学神+显眼包: 智力+30 / 压力+20 / 槽点"阳光学霸初印象"
    - 文青+段子手: 情商+30 / 魅力+10 / 爽点"全班哄堂大笑"
    - 段子手+卷王: 情商+50 / 智力+10 / 隐藏"NPC 好感+10"
    - I 人+显眼包: 体魄+30 / 压力+40 / 槽点"被迫社牛初印象"
```

**撰写八条铁律：**

1. **一句一行**——每条对话独立成行，方便美术配音
2. **3 句封顶**——旁白 + NPC 台词总共不超过 5 句
3. **性格分明**——不同性格看到的台词要有差异（见 5.8.6）
4. **埋伏笔**——关键对话暗示后续事件，引导出牌方向
5. **槽点爽点**——至少 1 句台词带"想吐槽"或"卧槽"的反应
6. **不要文学腔**——口语化、生活化、像真人在说话
7. **不要用「你」**——主角用名字或第三人称（「他/她」）
8. **不要重复信息**——流水账已经讲过的不再啰嗦

#### 5.8.5 立绘规范补充

**立绘分工：**

| 立绘 | 用途 | 表情数 |
|------|------|--------|
| 主角（6 种性格） | 出场/内心戏/关键选择 | 5-6 种 |
| 班主任 | 训话/表扬/批评 | 3-4 种 |
| 父母 | 家庭场景/转学/重要决策 | 3-4 种 |
| 重要 NPC（5-8 个） | 校园互动/情感线 | 3-4 种 |
| 颁奖 NPC | 颁奖典礼 | 2-3 种 |

**6 种性格主角的表情清单：**

| 性格 | 基础 6 表情 |
|------|------------|
| 🎓 学神型 | 平静 / 思考 / 紧张 / 自信 / 疲惫 / 兴奋 |
| 🌞 显眼包型 | 平静 / 热情 / 坚定 / 得意 / 关心 / 活力 |
| 😎 段子手型 | 平静 / 嬉皮 / 自嘲 / 得意 / 装傻 / 认真 |
| 🎨 文青型 | 平静 / 微笑 / 沉思 / 浪漫 / 陶醉 / 释然 |
| 🌙 I 人型 | 平静 / 沉思 / 浪漫 / 失落 / 陶醉 / 释然 |
| 🔥 卷王型 | 平静 / 微笑 / 沉思 / 坚定 / 自信 / 温和 |

> **表情设计原则**：去"愤怒/冷漠/不屑"等可能引发误解的表情；保留"平静/微笑"作为通用底色，让性格靠服饰和台词呈现。

**美术资源量估算：**
- 主角立绘：6 性格 × 6 表情 = 36 张
- NPC 立绘：10 个 × 3 表情 = 30 张
- 服装分层：3 套（校服/休闲/正装），通过换装复用
- **总计：66 张立绘 + 30 张服装配件**

**立绘切换规则：**
- 同一对话内表情可切换 1-2 次
- 旁白推进时，表情**不切换**（保持上一句的表情）
- 关键台词（⭐⭐⭐⭐⭐）必须有表情切换
- 切换时加 0.3 秒淡入淡出

### 5.9 卡牌升级系统（V1.2 新增）

#### 5.9.1 设计目标

**为什么要做升级系统？**
- 让玩家对卡牌有长期养成投入感
- 提升卡组深度，增加策略选择
- 给白嫖玩家（只领免费卡）也能跟上付费玩家的成长线

**核心约束：避免单一卡牌被滥用**
- 游戏设计的大忌：出现"万金油卡"——某张卡好用到玩家**只带这一张**、其他卡吃灰
- 升级系统**不能加速这种趋势**，反而要**强制轮换**——通过多样化升级条件 + 单局使用次数限制

#### 5.9.2 升级稀有度

```
白（Lv.1） → 绿（Lv.2） → 紫（Lv.3） → 金（Lv.4）
   ↑           ↑           ↑           ↑
 入门卡      进阶卡      资深卡      大师卡
```

| 稀有度 | 边框 | 属性加成 | 解锁效果 |
|--------|------|---------|---------|
| 🃏 白 Lv.1 | 灰色 | ±5~±20 | 基础效果 |
| 🟢 绿 Lv.2 | 绿色 | ±15~±50 | 数值 +50% |
| 🟣 紫 Lv.3 | 紫色 | ±30~±100 | 数值 +100% + 解锁额外词条 |
| 🟡 金 Lv.4 | 金色 | ±50~±200 | 数值 +200% + 解锁专属特效动画 |

#### 5.9.3 升级条件（多选组合制）

> **设计哲学**：升级条件**不能只用"使用次数"**——否则玩家会猛刷某张卡，导致其他卡被弃用。要混合**使用次数 / 道具 / 多样性 / 成就 / 性格**等多种条件。

##### 升级路径总览

| 升级 | 主条件 | 辅助条件（任选 1-2 个） | 设计意图 |
|------|--------|----------------------|---------|
| 白→绿 | 该卡使用 3 次 | **无** | 新手期容易升级，给正反馈 |
| 绿→紫 | 该卡使用 10 次 | + 在 3 种不同事件类型中使用过该卡 **+** 消耗 5 个"通用升级道具" | 强制轮换（不同事件类型）+ 道具门槛 |
| 紫→金 | 该卡使用 25 次 | + 解锁 1 个相关技能 **+** 消耗 1 个"专属升级道具" **+** 通关 1 次相关挑战关卡 | 后期多重门槛，防止单一卡被刷爆 |

##### 条件类型详解

| 条件类型 | 示例 | 适用阶段 | 防滥用机制 |
|---------|------|---------|-----------|
| 🔢 **使用次数** | 累计使用 10 次 | 全阶段（基础） | 仅作为基础条件之一 |
| 🎭 **多样性** | 在 3 种不同事件类型中使用过 | 绿→紫 | 强制玩家在学业/社交/竞赛等多种场景中使用 |
| 🎁 **道具消耗** | 5 个"通用升级道具" | 绿→紫、紫→金 | 道具来源多样，**不能纯靠刷一张卡获得** |
| 🏆 **成就解锁** | 解锁 1 个相关技能 | 紫→金 | 倒逼玩家用其他卡组配方 |
| 🎯 **挑战关卡** | 通关 1 次相关挑战 | 紫→金 | 必须用其他卡牌通关，强制熟悉整套卡组 |
| 🌟 **性格契合** | 性格卡只能由对应性格持有者升级到金 | 紫→金 | 鼓励专精一种性格 |
| 📅 **时间门槛** | 持有该卡至少 7 天 | 紫→金 | 防止新卡速成 |

#### 5.9.4 防滥用机制（核心）

##### 机制 1：单局使用次数限制

```
同一张卡在一局（30天）内：
  - 🃏 白卡：最多使用 3 次
  - 🟢 绿卡：最多使用 4 次
  - 🟣 紫卡：最多使用 5 次
  - 🟡 金卡：最多使用 6 次

达到上限后 → 卡牌变灰 + 提示"该卡本局已用尽，下局恢复"
```

**为什么稀有度越高反而能多用？**
- 高等级卡是玩家投入大量资源养成的，**不能完全废掉**
- 但即使是金卡，6 次/局也有限制
- 配合卡组 20 张的规模，玩家必须**轮换使用**

##### 机制 2：升级条件的多样性强制

| 阶段 | 升级条件中"使用次数"占比 | "其他条件"占比 |
|------|------------------------|---------------|
| 白→绿 | 100% | 0% |
| 绿→紫 | 33% | 67% |
| 紫→金 | 25% | 75% |

**设计意图**：越到后期，越不能靠单纯刷次数升级。必须用其他卡、做任务、攒道具。

##### 机制 3：冷门卡保护机制

```
系统自动监测：若某张卡连续 5 局玩家未使用
  ↓
触发"卡牌回忆"事件：随机在该局事件中插入该卡
  ↓
让玩家重新认识这张卡的功能
  ↓
弹出提示："好久没用【温柔安慰】了，要不要试试？"
```

##### 机制 4：升级资源稀释

| 升级道具 | 获取途径 | 用途 |
|---------|---------|------|
| 📘 通用升级道具 | 每日签到 + 竞赛奖励 + 事件掉落 | 绿→紫 通用消耗 |
| 💎 高级升级道具 | 每周任务 + 5 级以上竞赛 | 紫→金 高门槛消耗 |
| ⭐ 专属升级道具 | 特定隐藏事件 + 限定活动 | 紫→金 指定卡消耗 |

**关键**：升级道具**不能通过反复使用某张卡获得**——必须用其他卡/做其他事才能攒到，从根源上防止"单卡养金"。

#### 5.9.5 升级曲线（前期易/后期难）

```
        升级所需"总投入"
        ↑
   紫→金│            ╱
        │          ╱
        │        ╱
   绿→紫│      ╱
        │    ╱
        │  ╱
   白→绿│╱
        └─────────────────→ 卡牌等级
        Lv.1  Lv.2  Lv.3  Lv.4
```

## 8. 商业化设计（纯 IAA 模式）

> **设计原则**：本游戏采用 **纯 IAA（应用内广告）** 商业化模式，**不设任何 IAP（应用内购买）入口**。玩家完全免费。
>
> 设计哲学：**广告 = 加速器，不是门槛**。广告让玩家"轻松拿"而非"花钱买"。

### 8.1 商业模式

**核心公式：**
```
所有玩家 0 元 → 看广告 → 获得"加速奖励"（双倍/换牌/复活/卡组解锁）
                ↓
          广告收益 = 用户基数 × 广告频次 × eCPM
                ↓
        投放成本回收 + 利润 = 商业化目标
```

**与混合 IAA+IAP 的差异：**

| 维度 | 纯 IAA（我们采用） | 混合 IAA+IAP |
|------|--------------------|--------------|
| 玩家付费 | 0 | 0~数百元 |
| ARPU | 0.1~0.5 元/日 | 1~5 元/日 |
| 用户基数 | 大（无付费门槛） | 中（部分用户被门槛筛掉） |
| 设计约束 | 节奏更慢、奖励要克制 | 节奏可快、奖励可大方 |
| 适合类型 | IAA 小游戏爆款 | 中重度游戏 |

### 8.6 商业化对设计的约束

**设计必须遵守的 6 条红线：**

1. **不卡玩家**：广告不会"卡死"游戏进度。玩家永远有"不花钱/不看广告"的通关路径

3. **不强求点击**：激励视频永远是"自愿"，绝不强制全屏弹广告
4. **不污染体验**：广告内容不与游戏调性冲突（教育类游戏避开借贷/赌博广告）
5. **不刷屏**：同一广告位 60 秒内不重复展示
6. **不掉帧**：广告播放不影响游戏内性能（特别是低配机）
