## 1. 游戏概述

### 1.1 一句话定位
> "开局一把烂牌，看你能翻出什么花 —— 3分钟体验完整人生"

### 1.2 五大核心卖点
1. **沉浸感强**：动态背景 + 流水账剧情 + 事件弹出，像看一部可以干预的短剧
2. **策略感深**：20张卡牌构筑 + 6种性格 + 4维属性 + 5级竞赛
3. **反复玩价值高**：3局之内必有不同体验，30局仍有新鲜感
4. **节奏感爽**（V1.3 新增）：第 1 周目 7 天快闪、天天有钩子；广告与难度自然耦合，让"今天差不多了"和"明天继续来"成为本能
5. **长期养成爽**（V1.3 新增）：**周目限定卡 39 张可无限收集 + 4 级升级 + 卡组 1 张限定卡槽位 + 200+ 永久成就**——每完成一个周目 = 永久 +1 张卡 + 永久 +1-3 个成就，沉淀感极强

### 1.3 目标用户
- **核心**：18-35岁，怀念高中/想重新选择/有怀旧情怀
- **次核心**：喜欢剧情/卡牌/数值养成的玩家
- **泛用户**：解压/猎奇/社交炫耀玩家

### 1.4 差异化竞争
