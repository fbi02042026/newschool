## 1. V8 战略定位

### 1.1 一句话定位
> **"3 分钟爽一局，450 天养一生"** —— 主玩法试玩版已验证，V8 路线图是从试玩到上线的 5 阶段推进计划

### 1.2 三大核心战略
1. **试玩反馈驱动**：每一版 demo 都在试玩后改 5-10 个反馈点，不做大跃进
2. **系统逐步解锁**：从核心循环 → 精力系统 → 抽卡 → 阶段化 → 跨周目，分批实现避免一次做不完
3. **纯 IAA 商业化**：锁定后不再改，所有功能围绕"广告 = 加速器不是门槛"设计

### 1.3 五大目标
| 目标 | 度量 | 时间 |
|------|------|------|
| 核心循环跑通 | 1 局 5-10 分钟有完整体验 | ✅ V6.9.3 完成 |
| 试玩版通过 | 主人试玩后无重大反馈 | ⏳ V6.9.4 试玩版 |
| 内测版完成 | 抽卡 + 阶段化 + 卡牌 3 档全部就绪 | ⏳ V7.0 内测 |
| 公测版完成 | 40+ 结局 + 跨周目 + 限定卡全部就绪 | ⏳ V7.0 公测 |
| 正式上线 | 微信/抖音小游戏 + TapTap + App 全平台 | ⏳ V8 上线 |
